# Pocket Ops · 폐쇄망 미니 공구함

**v0.2.0 / 2026-10-04**

명령어가 기억나지 않을 때, 한글이 깨졌을 때, 로그와 목록을 정리할 때 꺼내 쓰는 로컬 HTML 작업실입니다. 실행 파일은 `pocket-ops.html` 한 개입니다. JavaScript, CSS, 명령어 데이터, 아이콘을 파일 안에 포함했습니다.

## 가장 빠르게 시작하기

1. `pocket-ops.html`을 작업 PC의 일정한 폴더에 저장합니다.
2. 기관의 HTML·JavaScript·망간 파일 반입 정책을 확인하고 허용된 절차로 옮깁니다.
3. 허용된 Chromium 기반 Chrome/Edge 브라우저에서 파일을 엽니다. HTML 편집기 대신 브라우저로 열어야 합니다.
4. 홈의 상황 카드 또는 `Ctrl+K`로 필요한 도구·명령어를 찾습니다.

**실행에 인터넷, 계정, API 키, Node.js, Python, WAS 설치가 필요하지 않습니다.** 압축본의 개발 소스나 테스트 파일도 실행에는 필요하지 않습니다. 단, 기관 브라우저가 로컬 HTML 또는 JavaScript 실행을 막으면 먼저 담당자에게 허용 여부를 확인하세요. 보안 정책을 우회하는 기능은 없습니다.

RHEL 7·JEUS 6 서버 위에 설치하는 제품이 아닙니다. 작업 PC의 브라우저에서 명령어를 확인하고 사용자가 터미널에 복사해 쓰는 도구입니다. IE / IE 호환 모드는 지원 대상이 아닙니다.

## 환경별 찾기와 배포

- **추천 도구:** 왼쪽 `내 작업실` → `공통 · 전체 / Windows / Linux / DB` 탭. 선택한 환경의 도구를 모아 보고 별표 항목을 먼저 표시합니다.
- **명령어와 대안:** 왼쪽 `명령어 포켓` → 환경 탭 → 분류/검색 → `값 넣기 · 복사`. 설치 조건을 확인하고, 도구가 없으면 항목의 `대체 명령어`를 각각 선택합니다. 대안은 기능 범위가 다를 수 있으며 자동으로 연속 실행하지 않습니다.
- **즐겨찾기:** 도구 또는 명령어의 별표 → 왼쪽 `즐겨찾기`. 두 종류를 한곳에서 볼 수 있습니다.
- **ZIP 배포:** 상단 `배포하기` → `pocket-ops-v0.2.0.zip` 저장. HTML 원본과 사용안내·변경 기록만 포함하며 작업 입력, 불러온 파일, 개인 명령어와 설정은 제외합니다. 기본 Windows ZIP 풀기와 호환되는 무압축 저장 방식입니다.
- **업데이트:** 연결 가능한 개발 PC → [GitHub 저장소](https://github.com/seamoon23/pocket-ops) → 최신 버전 ZIP → 승인된 망간전송 → 탐색기에서 `모두 압축 풀기` → `pocket-ops.html` 열기. `배포하기`는 현재 열어 둔 버전을 다시 포장하며 온라인 최신 버전 확인은 하지 않습니다.

Windows 예제는 Windows 11의 Windows PowerShell 5.1을 기준으로 합니다. Linux는 Ubuntu 22.04/RHEL 7의 기본 명령을 우선하고 `ss`, `ip`, `systemctl`, JDK·WAS·Docker 등 설치에 따른 차이는 항목에 표시합니다. DB 탭의 SQL은 해당 DB 클라이언트 편집기에 붙여 넣을 조회 예제입니다. PowerShell이나 SSH 셸에 붙여 넣지 마세요.

업데이트 전 `내 포켓 관리 → 설정 백업`을 저장하고, 새 파일은 별도 폴더에서 샘플로 시험한 뒤 `설정 가져오기`로 옮기세요. 저장소는 파일 경로에 따라 분리될 수 있습니다. 내려받은 ZIP/HTML의 파일 지문은 저장소의 `SHA256SUMS.txt`와 비교할 수 있습니다. Windows 시작 메뉴 → Windows PowerShell → 파일이 있는 폴더에서 `Get-FileHash -Algorithm SHA256 -LiteralPath .\pocket-ops-v0.2.0.zip`을 실행합니다. 체크섬은 손상 비교용이며 디지털 서명이나 보안 인증은 아닙니다.

## 세 가지 사용 예

### 포트를 알고 싶은데 root 계정은 없을 때

홈에서 ‘포트가 열려 있는지 궁금해요’를 누릅니다. ‘특정 포트 리스닝 확인’의 **값 넣기·복사**에서 `8111`을 입력하고 최종 명령어를 확인합니다.

```bash
ss -lnt "( sport = :8111 )"
```

조회 가능한 범위만 보여 줍니다. 리스닝, 방화벽 통과, 외부 접속 성공은 서로 같은 판정이 아닙니다. 검색 결과가 없다는 이유만으로 미설치를 단정하지 마세요. 이 앱은 위 명령을 실행하지 않습니다.

### 오래된 CSV/TXT 한글을 다시 읽고 싶을 때

‘한글·인코딩 진료소’에서 **원본 파일**을 선택합니다. UTF-8로 깨져 보이면 EUC-KR / Windows-949 계열을 선택하고 실제 내용을 대조합니다. 정상임을 확인한 뒤 UTF-8로 새 파일을 저장합니다. 원본을 덮어쓰지 않습니다. 일부 프로그램에 필요한 경우 UTF-8 BOM 옵션을 켭니다.

첨부한 `samples/korean-cp949.txt`에는 `갂`, `똠` 등 확장 한글이 포함되어 있습니다. 내용 비교용 UTF-8·UTF-16 파일도 제공합니다.

원본 바이트가 남아 있는 파일 재읽기와, 이미 깨진 문자열에서 바이트를 추측해 되살리는 것은 다릅니다. 복구 후보 기능은 Latin-1 또는 Windows-1252로 잘못 읽힌 경우만 가정합니다. 모든 한글 깨짐을 복원하지 않습니다. 이미 대체된 `�` 또는 `?`는 원래 정보가 없으면 확정 복원할 수 없습니다. UTF-8 내보내기만 지원하고 EUC-KR/CP949로 다시 저장하지는 않습니다.

### DB 조회용 ID 목록을 정리하고 싶을 때

‘텍스트 다듬기’에서 중복과 빈 줄을 정리한 뒤 ‘SQL IN 도우미’에 붙여넣습니다. 값의 종류를 문자열/숫자로 명시하고 컬럼명을 확인합니다. `00123`처럼 앞의 0이 의미 있다면 문자열을 선택합니다. 1,001개 이상은 기본 설정에서 OR 묶음으로 나눕니다.

숫자 모드는 숫자를 JavaScript Number로 변환하지 않아 긴 ID의 자릿수를 유지합니다. 문자열 모드는 DB별 이스케이프 해석 차이 때문에 역슬래시와 제어문자를 거절합니다. 이런 값은 실제 DB 클라이언트의 매개변수 바인딩을 사용하세요. 결과는 점검용 SQL 조건문이며 DB별 SQL 모드·바인딩·실행 계획 검토를 대신하지 않습니다.

## 찾기·개인화

`Ctrl+K` 또는 입력 칸 밖의 `/`로 통합 검색을 엽니다. 방향키와 Enter로 선택하고 Esc로 닫습니다. 상단의 달/해 버튼은 라이트·다크 전환입니다. 별표는 도구 또는 명령어 즐겨찾기입니다.

‘내 명령어 추가’는 명령어 원문을 저장합니다. 자동 치환이나 실행을 하지 않습니다. 비밀번호·토큰·개인정보를 넣지 마세요. 직접 저장한 명령어와 가져온 명령어는 모두 미검증 명령으로 취급하여 복사 전 확인을 요구합니다.

기본 명령어는 조회 중심, 부하 주의, 실제 변경으로 구분했습니다. 프로세스 종료, 권한 변경과 부하가 있는 작업은 내용을 확인해야 복사 버튼이 활성화됩니다. PID·포트는 형식/범위를 검사하고 Bash/PowerShell 매개변수는 인용합니다. 경로가 `-`로 시작하면 `./`를 붙이도록 안내합니다. 이러한 보조 장치가 실제 작업의 안전성을 보증하지는 않습니다.

## 저장되는 것 / 저장되지 않는 것

앱이 자동으로 영구 저장하는 것은 테마, 즐겨찾기, 사용자가 명시적으로 추가한 명령어뿐입니다. 로그, 변환 입력·결과, 선택한 파일 내용은 자동으로 localStorage에 저장하지 않습니다. 도구를 전환해도 입력은 현재 탭의 메모리에 남습니다.

‘내 포켓 관리 → 설정 백업’으로 JSON을 저장하면 개인 설정을 다른 PC로 옮길 수 있습니다. 백업에는 내 명령어 원문이 평문으로 포함됩니다. 입력 로그나 변환 결과는 포함되지 않습니다. 가져오기는 기존 설정을 교체하며 확인 창을 표시합니다.

설정 가져오기는 최대 16 MiB, 내 명령어 200개·각 8,000자까지 허용합니다. 보안 검토를 거치지 않은 사용자 명령으로 취급하며, 백업 파일의 위험도 표시는 신뢰하지 않습니다.

`file://`에서의 localStorage 동작은 브라우저·경로·관리 정책에 따라 달라질 수 있습니다. 파일 이름/위치나 PC를 바꾸기 전에 백업하세요. 저장소가 차단되면 경고를 표시하고 현재 탭에서만 설정을 유지합니다.

상단 휴지통은 현재 열린 도구의 입력·결과·파일 참조를 초기화합니다. 즐겨찾기와 내 명령어는 유지합니다. OS 클립보드, 다운로드한 파일, 브라우저 세션 복원, OS 메모리의 보안 삭제까지 처리하지는 않습니다.

## 외부 통신과 보안 범위

실행 HTML에는 외부 라이브러리, CDN, 원격 폰트, 분석 코드, 광고, API 호출이 없습니다. 메타 CSP에서 `connect-src 'none'`, `default-src 'none'` 등을 적용했습니다. 정규식은 로컬 Blob Worker에서만 실행하고 시간 초과 시 종료합니다. 입력 문자열을 HTML이나 JavaScript로 실행하지 않습니다.

이는 이 페이지 자체의 설계 범위입니다. 브라우저 확장 프로그램, OS 보안 프로그램, 클립보드 동기화, 관리 솔루션의 동작까지 통제하는 제품은 아닙니다. 업무 자료와 생성된 파일을 반출할 때는 기관 규정을 따르세요.

## 복사·파일 저장·브라우저 제한

자동 복사는 Clipboard API → 구형 copy 대체 경로 → 수동 선택/복사 창 순서로 시도합니다. 브라우저나 관리 정책상 자동 복사가 막혀도 텍스트를 직접 선택해 복사할 수 있도록 구성했습니다. API 사용에는 보안 컨텍스트와 권한 제한이 있고 대체 API는 deprecated입니다. 모든 관리형 브라우저의 성공을 보장하지 않습니다.

Web Crypto가 없는 컨텍스트에서는 해시 계산이 불가하다는 안내를 표시합니다. 명령어 포켓의 `sha256sum` 또는 PowerShell `Get-FileHash` 예제를 대신 참고할 수 있습니다. Worker가 차단되면 정규식을 메인 화면에서 강제로 실행하지 않고 중단합니다.

내부 HTTP 서버에 HTML을 올리는 것도 구조상 가능하지만 이 버전에서는 서버 배포를 검증하지 않았습니다. 특히 일반 HTTP에서는 일부 보안 컨텍스트 API에 제약이 있을 수 있습니다. 운영 배포 전 기관 환경에서 확인하세요.

자세한 결과와 미검증 범위는 `TEST_REPORT.md`, 기술 자료는 `SOURCES.md`를 참조하세요. 개발 소스와 빌드 방법은 `AGENTS.md`에 있습니다. 실행 HTML을 사용하기 위해 개발 환경을 설치할 필요는 없습니다.
