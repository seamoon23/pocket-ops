읽기 전용 명령어 참고

이 뷰어에서 JavaScript가 꺼져 있거나 차단되어 기본 명령어를 읽는 화면을 표시합니다. 인터넷이나 다른 파일은 필요하지 않습니다.

Windows · PowerShell / Linux · Bash / DB(CUBRID · MariaDB · Oracle · PostgreSQL)별 예제입니다. 각 명령의 입력 줄이 붙여넣을 곳(Linux 셸, PowerShell, csql>, MariaDB>, SQL>, psql =>)입니다. 명령어를 실행하지 않습니다. 검색·즐겨찾기·변환·자동 복사·값 검증·배포하기는 사용할 수 없습니다. 텍스트 길게 누르기·선택 복사는 뷰어 지원에 따라 가능합니다.

{{PORT}}, {{PATH}} 같은 표시는 입력 자리입니다. 그대로 실행하거나 단순 치환해 붙여넣지 마세요. 셸 인용·권한·대상 확인이 필요합니다. 값을 넣어 복사하려면 JavaScript를 지원하는 허용된 브라우저에서 이 파일을 여세요. 부하·변경 명령은 영향과 복구 절차를 먼저 확인하세요.
