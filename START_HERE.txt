Pocket Ops · 오프라인 작업 공구함

1. Windows 탐색기 → ZIP 파일 우클릭 → 모두 압축 풀기.
2. 압축을 푼 폴더 → pocket-ops.html 우클릭 → 연결 프로그램 → 허용된 Edge 또는 Chrome.
3. 왼쪽 메뉴 → 명령어 포켓 → Windows / Linux / DB → 항목 → 값 넣기·복사.
   복사 후 실제 터미널 또는 DB 도구에서 대상·권한·명령어를 확인하고 직접 실행합니다.
4. 도구/명령어의 별표 → 왼쪽 즐겨찾기에서 모아 봅니다.
5. 상단 배포하기 → 현재 열어 둔 버전의 ZIP을 저장합니다.
   인터넷 업데이트 확인은 하지 않습니다. 새 버전은 연결 가능한 개발 PC에서
   GitHub 저장소의 최신 배포 ZIP을 받아 기관의 승인된 망간전송 절차로 반입합니다.
6. 설정 이동: 왼쪽 내 포켓 관리 → 설정 백업 → 새 HTML의 설정 가져오기.
   작업 입력·파일·개인 명령어·즐겨찾기는 배포 ZIP에 포함되지 않습니다.
   개인 명령어는 설정 백업에 포함될 수 있으므로 그 백업은 별도로 관리합니다.

설치·서버·인터넷·로그인이 필요하지 않습니다. 로컬 HTML/JavaScript가 차단된
작업 PC에서는 담당자에게 허용 여부를 확인하세요. 정책 우회 기능은 없습니다.
서버 명령 실행, DB 접속, 자동 저장·자동 전송 기능은 없습니다.

업데이트 전에: 기존 원본과 설정 백업을 보관하고, 새 버전을 별도 폴더에 풀어
파일 열기 → 샘플 변환 → 복사 → 파일 저장 → 재실행을 확인하세요.
실제 업무 로그·인증정보 대신 제공된 샘플로 먼저 시험하세요.
