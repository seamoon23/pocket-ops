Pocket Ops · 오프라인 작업 공구함

v0.6.0 · PC/갤럭시 공통 · 실행에 필요한 파일은 pocket-ops.html 하나입니다.
별도 폴더·설치가 필요하지 않습니다. ZIP의 나머지 세 파일은 안내문입니다.

1. GitHub 저장소 → Releases → 최신 버전 → Assets → pocket-ops.html 받기.
   ZIP을 받았다면 Windows 탐색기 → ZIP 우클릭 → 모두 압축 풀기.
2. PC: 탐색기 → pocket-ops.html 우클릭 → 연결 프로그램 → 허용된 Edge/Chrome.
   갤럭시: 앱스 → 내 파일 → 다운로드 → pocket-ops.html → 표시되는 브라우저/HTML 뷰어.
   파일 연결 앱·기능 지원은 기기마다 다릅니다. 방문 전에 네트워크를 끄고 다시 열어 보세요.
3. 첫 화면(대시보드) → Windows PowerShell / Linux 셸 / DB 카드 → 항목 → 값 넣기·복사.
   카드의 "입력:" 줄이 붙여넣을 곳입니다(Linux 셸 $, PowerShell PS>, csql>, MariaDB>, SQL>, psql =>).
   복사 후 실제 터미널 또는 DB 도구에서 대상·권한·명령어를 확인하고 직접 실행합니다.
   도구가 없으면 창 아래 "사용할 수 없을 때"의 대안을 조건과 비교해 고릅니다. 입력한 값은 이어집니다.
4. 도구/명령어의 별표 → 왼쪽 즐겨찾기에서 모아 봅니다.
5. 상단 배포하기 → 현재 열어 둔 버전의 ZIP을 저장합니다.
   인터넷 업데이트 확인은 하지 않습니다. 새 버전은 연결 가능한 개발 PC에서
   GitHub 저장소의 최신 배포 ZIP을 받아 기관의 승인된 망간전송 절차로 반입합니다.
6. 설정 이동: 왼쪽 내 포켓 관리 → 설정 백업 → 새 HTML의 설정 가져오기.
   작업 입력·파일·개인 명령어·즐겨찾기는 배포 ZIP에 포함되지 않습니다.
   개인 명령어는 설정 백업에 포함될 수 있으므로 그 백업은 별도로 관리합니다.

DB 작업 순서 (CUBRID · MariaDB · Oracle · PostgreSQL)
첫 화면 → DB · SQL 작업대 → DB 선택 (또는 메뉴 → 서버 운영 → SQL 작업대).
1 접속: Linux 셸에 접속 명령을 붙여넣고 비밀번호는 클라이언트 프롬프트에 입력합니다.
2 확인: csql> / MariaDB> / SQL> / psql => 에서 접속 대상과 자동 커밋 상태를 확인합니다.
3 시작: MariaDB는 START TRANSACTION;, PostgreSQL은 BEGIN;을 먼저 실행합니다.
4 쿼리: SELECT/INSERT/UPDATE/DELETE 프리셋 → 테이블명·값·WHERE 수정 → 복사.
  변경 SQL은 확인 창의 최종 SQL을 읽고 복사합니다. WHERE가 없으면 위험 확인 체크가 필요합니다.
5 확정: 영향 행 수가 예상과 다르면 확정하지 말고 ROLLBACK 하세요.
  Oracle SQL*Plus의 EXIT는 기본적으로 커밋합니다. EXIT ROLLBACK을 사용하세요.

JavaScript를 실행하지 않거나 스크립트를 차단하는 HTML 뷰어에서는 같은 파일의
읽기 전용 명령어 참고가 표시됩니다(차단된 경우 약 1.5초 뒤). Windows/Linux/DB 분류 링크로 기본 명령어와 주의사항을 볼 수 있습니다.
검색·즐겨찾기·변환·자동 복사·값 검증·배포하기는 사용할 수 없습니다.
{{PORT}} 같은 입력 자리는 그대로 실행하지 마세요. HTML 원문만 표시하거나
HTML 자체를 차단하는 앱에서는 참고 화면도 표시되지 않습니다.

설치·서버·인터넷·로그인이 필요하지 않습니다. 로컬 HTML/JavaScript가 차단된
작업 PC에서는 담당자에게 허용 여부를 확인하세요. 정책 우회 기능은 없습니다.
서버 명령 실행, DB 접속, 자동 저장·자동 전송 기능은 없습니다.

업데이트 전에: 기존 원본과 설정 백업을 보관하고, 새 버전을 별도 폴더에 풀어
파일 열기 → 샘플 변환 → 복사 → 파일 저장 → 재실행을 확인하세요.
실제 업무 로그·인증정보 대신 제공된 샘플로 먼저 시험하세요.
